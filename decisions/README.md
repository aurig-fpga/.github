# Decisions

A decision document is a numbered, public record of a technical contract that applies across the AURIG suite. Each decision changes only through a pull request to this repository.

## Status values

- **Proposed**: under discussion, not yet binding.
- **Accepted**: the contract is in force. Implementation in the affected repositories may still be in progress.
- **Superseded by NNNN**: replaced by decision NNNN, which takes precedence.
